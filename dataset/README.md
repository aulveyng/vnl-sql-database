# Datasets

This directory contains the datasets used to populate the PostgreSQL database.

## Included Files

- teams.csv
- coaches.csv
- players.csv
- schedule.csv
- matches.csv
- team_match_stats.csv
- standing_history.csv
- predictions.csv

## Data Source

The datasets were manually encoded and compiled from publicly available Volleyball Nations League (VNL) statistics and match information.

## Notes

Player-level statistics, match lineups, weekly rosters, and historical world rankings are planned for future releases.
