# Machine Learning

This directory contains the notebooks, trained models, and outputs used to predict Volleyball Nations League match outcomes.

## Workflow

1. Data preprocessing
2. Logistic Regression
3. Random Forest
4. Gradient Boosting
5. Model comparison
6. Week 3 prediction

## Models Evaluated

- Logistic Regression
- Random Forest
- Gradient Boosting Classifier

## Selected Model

Random Forest achieved the best overall predictive performance and was selected as the final production model.

## Outputs

- Trained models (.pkl)
- Evaluation metrics
- Feature importance
- Week 3 predictions
